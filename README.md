🗺️ GeoTracker: Картограф
Умный трекер продуктивности для картографов, работающих с панорамами.

📖 Описание
GeoTracker: Картограф — это десктопное приложение, созданное для картографов, которые работают в Яндекс.Картах или аналогичных сервисах. Оно превращает рутинный процесс расстановки точек в увлекательную игру с элементами геймификации, статистики и финансового учёта.

Приложение помогает:

Отслеживать количество выполненных точек за день и за всё время.

Работать по спринтам с перерывами для сохранения продуктивности.

Видеть реальную скорость работы (точек в час) и заработок.

Анализировать свою продуктивность с помощью графиков и статистики.

Ставить цели и следить за их выполнением.

Получать мгновенный дофаминовый отклик от каждого действия.

🛠️ Установка и запуск
1. Клонирование репозитория
bash
git clone https://github.com/your-username/geotracker-cartographer.git
cd geotracker-cartographer
2. Установка зависимостей
bash
pip install -r requirements.txt
Если файла requirements.txt нет, установите вручную:

bash
pip install keyboard matplotlib
3. Запуск приложения
bash
python main.py
4. Настройка перед использованием
Убедитесь, что у вас открыта вкладка с панорамами в браузере (например, "Бэкофис Панорамы").

Нажмите "Старт" в главном окне, чтобы начать сессию.

Добавляйте точки с помощью глобального хоткея Ctrl+A (или кликом по окну приложения).

Настройте длительность спринтов и цену точки в окне "Настройки" (⚙️).

⚙️ Настройка
Основные параметры
Длительность спринта – время работы до перерыва (5–60 минут).

Длительность перерыва – время отдыха между спринтами (1–15 минут).

Количество повторов – сколько раз повторять цикл «спринт → перерыв».

Цена точки – стоимость одной точки в рублях (по умолчанию 1.3).

Интервал автосохранения – как часто сохранять прогресс (в секундах).

Включить звуки – глобальное отключение звуковых сигналов.

Автоматическая корректировка цели – предлагать увеличить цель при перевыполнении.

Файлы данных
progress.json – содержит все сессии, рекорды и общее количество точек.

settings.json – хранит настройки пользователя.

Эти файлы создаются автоматически при первом запуске.

🧠 Как это работает
Сессия – период работы от нажатия «Старт» до «Стоп».

Спринт – часть сессии, ограниченная по времени.

Точка – единица работы (добавляется хоткеем Ctrl+A).

Продуктивное время – время, проведённое во вкладке «Бэкофис Панорамы» во время спринта.

Скорость – количество точек в час продуктивного времени.

Заработок – произведение количества точек на цену точки.

🐛 Известные проблемы и их решение
Скорость показывает прочерк – убедитесь, что вы работаете во вкладке, в названии которой есть слова "панорам" и "бекофис" (или "яндекс"). Если нет – добавьте свой маркер в config.py (переменная PRODUCTIVE_TAB_MARKERS).

Ошибка при сохранении – проверьте права на запись в папке с приложением.

Глобальный хоткей не работает – запустите приложение от имени администратора.
