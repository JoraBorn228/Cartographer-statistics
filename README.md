## 📖 Описание

**GeoTracker: Картограф** — это десктопное приложение для геймификации работы картографов. Оно превращает рутинный процесс расстановки точек в увлекательную игру с элементами статистики, финансового учёта и достижений.

Приложение работает в фоновом режиме, отслеживает активные вкладки браузера (например, «Бэкофис Панорамы»), начисляет очки за каждую выполненную точку и помогает анализировать вашу продуктивность.

### 💡 Что умеет приложение

- 📊 Отслеживание точек за день и за всё время
- ⏱️ Работа по спринтам с перерывами, прогресс‑бар теперь выше (14 px) и показывает процент выполнения
- ⏱️ **Время текущей сессии** отображается в шапке окна
- ⚡ История скорости работы (точек/ч) и мини‑график скорости в реальном времени
- 💰 Финансовый учёт — конвертация точек в рубли
- 📈 Графики и аналитика продуктивности
- 🎯 Постановка целей с прогнозом времени выполнения
- 🔔 Звуковые уведомления и визуальные эффекты
- 📋 Улучшенные карточки статистики с цветными акцентными полосками и hover‑эффектом

## 🛠️ Установка и запуск

### 1. Клонирование репозитория

```bash
git clone <your-repo-url>
cd geotracker-cartographer
```

### 2. Установка зависимостей

```bash
pip install -r requirements.txt
```

> Если файла `requirements.txt` нет, установите вручную:
> ```bash
> pip install keyboard matplotlib numpy
> ```

### 3. Запуск приложения

```bash
python src/main.py
```

### 4. Настройка перед использованием

1. Откройте вкладку с панорамами в браузере (например, **«Бэкофис Панорамы»**)
2. Нажмите **«Старт»** в главном окне
3. Добавляйте точки через глобальный хоткей **Ctrl+A**
4. Настройте параметры в окне **«Настройки»** (⚙️)

## ⚙️ Настройка

### Основные параметры

| Параметр | По умолчанию | Описание |
|---|---|---|
| Длительность спринта | `15 мин` | Время работы до перерыва (5–60 мин) |
| Длительность перерыва | `5 мин` | Время отдыха между спринтами (1–15 мин) |
| Количество повторов | `1` | Циклов «спринт → перерыв» |
| Цена точки | `1.3 ₽` | Стоимость одной точки в рублях |
| Интервал автосохранения | `60 сек` | Частота сохранения прогресса |
| Звуковые уведомления | `Вкл` | Глобальное отключение звуков |
| Автокорректировка целей | `Вкл` | Предложение увеличить цель |

### Файлы данных

| Файл | Описание |
|---|---|
| `progress.json` | Сессии, рекорды, общее количество точек |
| `settings.json` | Настройки пользователя |
| `profiles.json` | Профили пользователей |

> Файлы создаются автоматически при первом запуске.

## 🧠 Как это работает

### Основные понятия

| Термин | Описание |
|---|---|
| **Сессия** | Период работы от «Старт» до «Стоп» |
| **Спринт** | Временной отрезок интенсивной работы |
| **Перерыв** | Отдых между спринтами |
| **Точка** | Единица работы (добавляется через Ctrl+A) |
| **Продуктивное время** | Время в активной вкладке «Бэкофис Панорамы» |
| **Скорость** | Точек в час продуктивного времени |
| **Заработок** | Количество точек × цена точки |

### Рабочий процесс

```
Нажатие «Старт»
       │
       ▼
  ┌─────────┐
  │  СПРИНТ  │ ← Отслеживаем вкладки, начисляем точки по Ctrl+A
  └────┬────┘
       │ время вышло
       ▼
  ┌─────────┐
  │ ПЕРЕРЫВ  │ ← Отдых, приложение считает статистику
  └────┬────┘
       │ перерыв окончен
       ▼
  ┌─────────┐
  │ СПРИНТ x2│ ← Повторяем, если настроено
  └────┬────┘
       │
       ▼
  Нажатие «Стоп» → Сессия сохранена
```

## 🐛 Решение проблем

| Проблема | Решение |
|---|---|
| Скорость показывает «—» | Убедитесь, что открыта вкладка с названием, содержащим **«панорам»** и **«бекофис»** (или **«яндекс»**). Добавьте свой маркер в `config.py` (`PRODUCTIVE_TAB_MARKERS`) |
| Ошибка при сохранении | Проверьте права на запись в папке с приложением |
| Хоткей не работает | Запустите приложение от имени администратора |
| Приложение не определяет вкладку | Откройте вкладку браузера с панорамами перед запуском сессии |
